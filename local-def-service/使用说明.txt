CFX 工程工具箱本地服务 V2.1
================================

一、启动
1. 必须先完整解压 ZIP，不能在压缩包预览窗口中直接运行。
2. 双击“启动CFX批量转DEF.bat”。本地服务固定使用 http://127.0.0.1:62356/。
3. Windows 第一次可能显示“未知发布者”安全提示，这是下载的批处理文件未进行商业数字签名所致；确认文件来自本次工具包后点击“运行”。
4. 启动后会保留一个黑色 PowerShell 服务窗口，并自动在默认浏览器打开网页。转换期间不要关闭黑色窗口。

二、操作
1. “批量选择文件”：一次选择多个 .cfx。
2. “扫描文件夹”：递归查找文件夹及其子目录中的全部 .cfx。
3. 选择 DEF 输出目录。
4. 工具自动查找 cfx5pre.exe；未找到时手动选择：
   ...\ANSYS Inc\vXXX\CFX\bin\cfx5pre.exe
5. 选择同名文件处理方式后，点击“开始批量转换”。
6. 工具箱“CFX-Post 批量导出”模块连接本服务后，可用系统选择器导入结果文件，并自动识别公共结果目录；服务未连接时自动使用普通浏览器导入，不会恢复历史目录。

三、工具结构
- 浏览器：显示任务、进度和日志。
- server.ps1：仅监听本机 127.0.0.1:62356，负责文件选择和任务管理；只允许工具箱 GitHub 页面及本机页面跨域调用。
- worker.ps1：调用本机 cfx5pre.exe 生成 .def。
- 文件不会上传到互联网。

四、关闭
优先点击网页右上角“退出工具”。也可直接关闭黑色服务窗口；正在运行的转换进程会随之终止。

五、常见问题
1. 双击 BAT 后仍立即关闭：查看同目录 server-error.log。
2. 网页没有打开：在黑色窗口中找到 http://127.0.0.1:62356/，复制到浏览器。
3. 未找到 CFX-Pre：手动选择 cfx5pre.exe。
4. 转换失败：查看网页日志。模型存在 Physics Errors、许可证不可用、版本不兼容时，CFX-Pre 无法生成 DEF。
5. 不希望每次出现下载安全警告：右键 ZIP 或 BAT → 属性 → 勾选“解除锁定/Unblock”（若系统显示该选项），再解压运行。
