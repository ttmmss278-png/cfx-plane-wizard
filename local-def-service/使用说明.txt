Pelton 工程工具箱统一本地服务 V2.4.0
======================================

一、这个安装包有什么用
1. “CFX-Post 批量导出”使用它读取所选结果文件的完整路径。
2. “CFX 批量转 DEF”使用它选择本机文件和目录，并调用 CFX-Pre 完成转换。
3. 两个模块共用同一个服务、同一个端口和同一个安装包，不需要分别安装。
4. 文件始终在本机处理，不会上传到 GitHub 或其他服务器。

二、换电脑后首次使用
1. 下载 Pelton-Toolbox-Local-Service-Windows.zip。
2. 完整解压 ZIP；不要在压缩包预览窗口中直接运行 BAT。
3. 双击“安装并启动本地服务.bat”。不需要管理员权限，也不需要 Node.js/npm。
4. 安装文件会复制到当前用户的：
   %LOCALAPPDATA%\PeltonToolbox\LocalService\2.4.0
5. 安装后可删除下载的 ZIP 和解压目录，不影响以后从网页启动。
6. 返回 GitHub Pages 页面。浏览器首次询问是否打开 pelton-toolbox 链接或允许本地网络访问时，请选择允许。

三、日常使用
1. 在“批量导出”或“批量转 DEF”模块的服务条中点击“启动本地服务”。
2. 保持出现的 PowerShell 服务窗口开启。
3. 页面显示“本地服务已连接”后使用对应的本机功能。
4. 也可在安装目录中双击“启动本地服务.bat”手动启动。

四、CFX 批量转 DEF 的额外要求
1. 本机必须已安装 ANSYS CFX-Pre。
2. 自动检测失败时，手动选择：
   ...\ANSYS Inc\vXXX\CFX\bin\cfx5pre.exe
3. 转换是否成功还受许可证、模型物理设置与 CFX 版本影响。

五、安全边界
1. 服务只监听 http://127.0.0.1:62356/，不对局域网或互联网开放。
2. API 校验网页来源，并使用每次启动随机生成的本地会话令牌。
3. 服务包不包含用户结果、日志或历史任务。

六、常见问题
1. 点击启动没有反应：先确认已经完整解压并运行过“安装并启动本地服务.bat”。
2. 页面一直显示未连接：确认 PowerShell 窗口仍开启，并在浏览器站点设置中允许“本地网络访问”。
3. 端口被占用：关闭旧的 Pelton 本地服务窗口后重新启动。
4. BAT 立即关闭：查看安装目录下 local-def-service\server-error.log。
5. Windows 显示“未知发布者”：这是未使用商业代码签名的本地脚本。请只运行从工具箱官方页面下载的安装包；ZIP 的版本、大小和 SHA256 可在 https://ttmmss278-png.github.io/cfx-plane-wizard/downloads/local-service-manifest.json 核对。
