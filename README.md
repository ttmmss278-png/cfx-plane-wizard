# 冲击式水轮机工程工具箱

将常用 CFX 前后处理、批量求解、几何处理、数据管理与数值验证工具整合到统一入口，提供模块导航、搜索、帮助、刷新、独立打开和全屏操作。各工具以独立模块运行，尽量保持原有计算逻辑、文件处理和下载能力，同时通过 iframe 隔离不同模块的 CSS、DOM 与脚本。

## 功能模块

| 编号 | 模块 | 运行方式 |
| --- | --- | --- |
| 01 | CFX-Post 批量导出 | 浏览器 + 可选本地服务 |
| 02 | CFX 连跑 BAT 生成器 | 纯浏览器 |
| 03 | 截面二维归一化投影 | 纯浏览器 |
| 04 | CFX-Post 圆截面生成器 | 纯浏览器 |
| 05 | CFX 批量转 DEF | 本机 PowerShell 服务 + CFX-Pre |
| 06 | CFX-Post 公式与命令库 | 纯浏览器 + 可选 GitHub 私有数据同步 |
| 07 | 网格无关性验证 | 纯浏览器 |
| 08 | 射流质量分级评价与智能优选 | 纯浏览器 |

## 本地开发

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

构建静态文件：

```bash
npm run build
npm run preview
```

## 使用全部功能

Windows 下双击根目录的 `启动工程工具箱.bat`。首次运行会自动安装依赖并构建，然后启动仅监听 `127.0.0.1` 的本地服务。

如果希望从在线网页直接启动第 05 个模块的本地服务，只需在当前电脑运行一次根目录的 `安装网页启动器.bat`。安装后，点击网页中的“启动本地服务”即可；浏览器首次调用时可能会询问是否打开 `pelton-toolbox` 链接，请选择允许。该启动器仅写入当前 Windows 用户，不需要管理员权限。

除第 05 个模块外，其余模块均可直接使用静态部署版本。第 05 个“CFX 批量转 DEF”需要：

1. Windows PowerShell；
2. 本机已安装 ANSYS CFX-Pre；
3. 保持启动工具箱时出现的 PowerShell 窗口开启。

静态部署（包括 GitHub Pages）不能直接调用本机 CFX-Pre，因此该模块会显示“需本地服务”提示。

## 项目结构

```text
src/                         统一工具箱外壳与主题系统
public/modules/              8 个工程功能模块
local-def-service/           批量转 DEF 的本地服务与工作脚本
启动工程工具箱.bat             Windows 一键启动入口
```

## 数据与隐私

工程文件均在浏览器或本机处理，不会自动上传。第 01 个“CFX-Post 批量导出”可选用本地服务读取用户本次选择的完整文件路径；服务未连接时退回普通浏览器导入，不恢复上次公共目录。第 06 个“CFX-Post 公式与命令库”只有在用户主动配置后，才会通过 GitHub API 向私有数据仓库同步公式、CCL、分类和文件夹数据；GitHub Token 默认只保存在当前浏览器会话中。第 07、08 个数值评价模块仅在浏览器本地处理输入与计算。
