使用说明

CFX-Post 批量输出图片与表格

返回生成器

1. 打开网页

建议从 GitHub Pages 工程工具箱进入“CFX-Post 批量导出”。直接打开当前目录的 index.html 仍可生成命令，但只能使用普通浏览器导入；若要自动识别所选结果文件的完整路径，必须从 GitHub Pages 工具箱进入，再在顶部下载统一服务包，完整解压并运行 安装并启动本地服务.bat。安装一次后，日常只需点击“启动本地服务”。

如果需要查看本说明，双击同一文件夹里的 使用说明.html，或在生成器右上角点击“使用说明”。

2. 功能用途

这个网页用于根据 CFX-Post 2020 的输出需求，自动生成 POST command 代码。把生成的代码复制到 CFX-Post 中运行，即可批量导出多个结果文件中的图片和表格。

  • 可只输出图片、只输出表格，或同时输出图片和表格。
  • 图片和表格可以保存到不同文件夹。
  • 图片可按需选择 VIEW1、VIEW2 等视图。
  • 表格可按需选择 B1、B2 等对象。
  • 支持设置图片宽度、高度、格式、背景和画质。
  • 支持配置方案保存、载入、删除、JSON 导入导出及参数草稿自动恢复。
  • 支持复制代码或下载 .cse 命令文件。

2.1 配置方案与草稿恢复

页面顶部的“配置方案”用于复用常见导出设置。填写方案名称后点击“保存当前”，即可保存输出开关、图片与表格参数、命令模板、图片视图和表格对象；在“已保存方案”中选择后，可以载入或删除。

“导出 JSON”会导出当前页面上的参数，“导入 JSON”会把配置加入方案列表并立即载入，适合备份或在另一台设备上复用。浏览器本地数据被清理时，本地方案也会删除，重要方案建议同时导出 JSON 备份。

修改导出参数后，页面会自动保存参数草稿，下次打开时恢复。为了避免误用旧算例，以下临时数据永远不会写入方案、草稿或 JSON，也不会在刷新后恢复：

  • 公共结果目录；
  • “结果文件绝对路径 / 文件名”中的手动清单；
  • 通过浏览器或本地服务导入的结果文件；
  • 本地服务连接状态和会话令牌。

因此，即使恢复了草稿，未连接本地服务时公共结果目录仍为空，必须为当前算例重新导入结果文件或手动填写目录。

3. 第一个模块：导入结果与保存位置

3.1 导入结果文件

点击“导入结果文件”，可以一次选择多个 CFX 结果文件，例如：

case01.res
case02.res
case03.res

导入一次后仍可继续点击“导入结果文件”追加下一批文件。新文件会接在原列表后面；重复选择的文件会自动跳过，不会覆盖或清空之前已经导入的文件。

需要自动识别完整路径时，新电脑先点击模块顶部服务条里的“下载服务包”，完整解压 ZIP 后双击 安装并启动本地服务.bat；以后只需点击“启动本地服务”。页面会在后台静默检测服务；检测到服务后，导入按钮显示“本地服务已连接”，系统选择器会返回完整路径并自动识别公共结果目录。未连接时导入按钮立即使用普通浏览器导入，只生成文件名清单，不会读取或恢复上次使用的公共目录。

导入后，每个文件条目右侧都有“删除”按钮。误选文件时可单独移除；当最后一个由本地服务导入的文件被删除时，对应的自动公共目录也会一并清空。

3.2 公共结果目录

普通导入只显示文件名时，请在“公共结果目录”中填写本次结果文件所在的文件夹：

D:\CFX\cases

网页会自动组合为：

D:\CFX\cases\case01.res
D:\CFX\cases\case02.res

如果你在下方文本框中粘贴完整路径，网页会自动提取公共结果目录。例如粘贴 D:\CFX\cases\case01.res 和 D:\CFX\cases\case02.res 后，公共结果目录会自动变成 D:\CFX\cases。

3.3 手动输入结果文件绝对路径

也可以直接在“结果文件绝对路径 / 文件名”中粘贴完整路径，每行一个：

D:\CFX\cases\case01.res
D:\CFX\cases\case02.res
D:\CFX\cases\case03.res

如果希望 CFX-Post 直接运行，建议使用完整绝对路径。

4. 第二个模块：输出内容与参数

4.1 输出图片或表格

模块顶部有“输出图片”和“输出表格”两个开关。打开网页时两个开关默认都不勾选；两个都打开时，会同时生成图片和表格输出命令；只打开其中一个时，只生成对应命令。

4.2 图片输出文件夹

填写图片保存目录，例如：

D:\CFX\exports\images

生成的图片会按算例名和视图名命名：

case01_streamline.png
case01_view2.png

4.3 表格输出文件夹

填写表格保存目录，例如：

D:\CFX\exports\tables

当前表格格式默认是 TXT。实现方式是两步：先让 CFX-Post 用已验证可用的 >table save 写出 CSV 中间文件；CFX-Post 运行完成后，再运行网页右侧生成的 PowerShell 转换脚本，把 CSV 转成固定宽度 TXT。TXT 中每一列会按最大列宽补空格，并将单元格内容居中对齐。生成文件示例：

case01_B1.txt
case01_B2.txt

4.4 图片视图

在“图片视图”区域勾选需要输出的视图。默认列表包含 VIEW1、VIEW2 等示例，但默认都不勾选。第一列名称应与你 CFX-Post 里的 View 名称一致，第二列是导出文件名里使用的别名。

VIEW1  streamline
VIEW2  pressure
VIEW3  velocity

4.5 图片参数

  • 宽度和高度：例如 1920 x 1080。
  • 格式：PNG、JPG、TIF、BMP。
  • 背景：白色背景、保持当前背景、透明背景。
  • 图片命名前缀：默认 {case}_{view}。
  • 抗锯齿：建议开启。

{case} 表示当前结果文件名，不含扩展名；{view} 表示当前视图别名。

4.6 表格对象

在“表格对象”区域勾选需要输出的表格。默认列表从 B1 开始，但默认不勾选；名称必须与你 CFX-Post 里的表格对象名称完全一致，包括大小写。如果你的表格实际叫 LOSS 或 loss，请把 B1 改成对应名称。

B1
B2
B3

4.7 表格参数

表格格式默认是 TXT。选择 TXT 时，POST command 会先保存同名 CSV 中间文件；然后使用右侧“CSV 转 TXT 脚本”把 CSV 转成列宽对齐的 TXT。如果你希望保留原始 CSV，表格格式可以切换为 CSV。表格命名前缀默认是 {case}_{table}。

5. 第三个模块：POSTcommand 代码生成

网页右侧会实时生成 POST command 代码。填写或修改任何选项后，右侧代码会自动更新。

  • 点击“复制代码”复制右侧全部代码。
  • 点击“下载 CSE”下载为 cfx-post-batch-export.cse。
  • 当表格格式选择 TXT 时，右侧还会生成“CSV 转 TXT 脚本”。请先运行 CFX-Post 命令导出 CSV，再下载并运行该 .ps1 脚本生成居中对齐 TXT。

6. 在 CFX-Post 2020 中使用

  1. 在网页中填好结果文件、图片、表格和输出目录。
  2. 点击“复制代码”或“下载 CSE”。
  3. 打开 CFX-Post 2020。
  4. 将代码粘贴到 CFX-Post 的 command/session 执行位置，或加载下载的 .cse 文件。
  5. 运行命令。
  6. 如果表格格式选择 TXT，等待 CFX-Post 命令执行完成后，下载右侧“CSV 转 TXT 脚本”，右键选择“使用 PowerShell 运行”，或在 PowerShell 中执行该脚本。
  7. 到图片输出文件夹和表格输出文件夹检查结果。

7. 高级命令模板

第三个模块里有“高级命令模板”。如果你的 CFX-Post 2020 对某些命令格式要求不同，可以直接修改模板。

常见需要调整的地方包括加载结果文件命令、切换视图命令、HARDCOPY 图片参数和表格导出命令中的 table save 语法。CFX-Post 2020 的默认表格输出命令使用 >table save={tableSaveFile}, name={table}，不带 separator 参数。

TXT 表格不是直接由 >table save 写出，而是先写出 CSV 中间文件，再由网页生成的 PowerShell 脚本读取 CSV、计算每列宽度、写出居中对齐的固定宽度 TXT，最后删除 CSV 中间文件。查看 TXT 时建议使用等宽字体，例如 Consolas；如果使用比例字体，空格对齐看起来可能仍不整齐。

CFX-Post 2020 的默认视图切换命令使用 >setViewportView cmd=set, viewport=1, view={view}。如果缺少 cmd=set，Command Editor 会提示必须指定 copy、set 或 update。如果给视图名额外加双引号，CFX-Post 可能会把引号当成视图名的一部分，例如去查找 "Z1" 而不是 Z1。

CFX-Post 官方示例通常使用正斜杠路径，例如 c:/case/results.res。生成器会把 Windows 反斜杠路径自动转换为正斜杠，例如 F:\cfx_result\jiami\JM\15.res 会输出为 F:/cfx_result/jiami/JM/15.res。

图片输出默认先设置 HARDCOPY 参数，然后使用 >print {imageFile} 写出图片。这样比在 HARDCOPY 块里写 Hardcopy Filename 更接近官方示例，也能避免部分 CFX-Post 2020 环境执行完成但不写图片的问题。

CFX-Post 2020 的默认加载结果命令使用 >load filename={resultFile}。不要在默认模板中加入 mode=replace，否则 Command Editor 会提示 Invalid parameter in load: 'mode'。如果报文件不存在并且错误里显示 '"F:\...res"'，说明双引号被当成文件名的一部分，需要使用不带双引号的加载模板。

8. 常见问题

8.1 为什么双击 HTML 打不开？

请使用新版 Edge 或 Chrome 打开工程工具箱；独立运行时打开当前目录的 index.html。普通浏览器导入不会获得完整本机路径，这是浏览器安全限制。

8.2 为什么导入文件后没有完整路径？

这是浏览器安全限制。启动本地服务后重新聚焦页面，导入按钮会显示“本地服务已连接”，此时可自动读取完整路径；服务未连接时会直接使用普通导入，请粘贴完整路径或手动填写本次“公共结果目录”。普通导入不会恢复历史目录。

8.3 为什么 CFX-Post 没有导出图片？

请检查结果文件路径、图片输出文件夹、VIEW1/VIEW2 名称，以及当前 CFX-Post 2020 是否支持模板里的视图切换命令。图片输出文件夹需要提前创建，例如 F:\cfx_result\jiami\15_90picture 必须已经存在；CFX-Post 通常不会自动创建不存在的目录。

8.4 为什么 CFX-Post 没有导出表格？

请检查表格对象名称、表格输出文件夹，以及表格模板里的 table save 语法是否适合你的 CFX-Post 2020。

8.5 为什么恢复草稿后没有结果文件和公共目录？

这是有意的安全设计。草稿和配置方案只恢复导出参数，不记录当前算例的结果路径、文件列表或本地服务会话，防止下次打开时误把新任务导出到旧算例目录。请重新导入本次结果文件。
