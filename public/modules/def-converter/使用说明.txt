CFX 批量转 DEF — GitHub 前端版 V3.1
====================================

一、运行方式
1. 工具界面始终使用 GitHub Pages 最新版本。
2. CFX-Post 批量导出与本模块共用同一个 Pelton 本地服务包，不需要分别下载 BAT。
3. 未启动本地服务时，工具箱及其他纯浏览器功能仍可正常使用；只有本机文件选择和 CFX→DEF 实际转换不可用。
4. 本地 PowerShell 只负责文件选择、目录选择、CFX-Pre 检测和转换，文件不会上传。

二、换电脑后首次使用
1. 在模块顶部服务条中点击“下载服务包”。
2. 完整解压 Pelton-Toolbox-Local-Service-Windows.zip；不要直接从压缩包预览窗口运行。
3. 双击“安装并启动本地服务.bat”。不需要管理员权限或 Node.js/npm。
4. 返回本模块；页面会自动检测本地服务。
5. 浏览器首次询问是否打开 pelton-toolbox 链接或允许本地网络访问时，请选择允许。

三、日常操作
1. 点击模块顶部服务条中的“启动本地服务”。
2. 保持 PowerShell 服务窗口开启，等待页面显示“本地服务已连接”。
3. 选择 .cfx 文件、DEF 输出目录和 cfx5pre.exe。
4. 点击“开始批量转换”。

四、本地接口
本地服务固定监听：http://127.0.0.1:62356/
服务只监听本机，默认只允许官方工具箱 GitHub Pages 调用；开发人员显式使用 -AllowDevelopmentOrigins 启动时，才额外允许本机开发页面。

五、关闭
优先点击页面右上角“退出工具”；也可直接关闭 PowerShell 服务窗口。正在运行的转换进程会随服务停止。

六、常见问题
1. 点击启动没反应：重新下载完整服务包并运行“安装并启动本地服务.bat”，不能只复制一个 BAT。
2. 页面一直显示未连接：确认服务窗口开启，并在站点权限中允许“本地网络访问”。
3. 未找到 CFX-Pre：手动选择 ...\ANSYS Inc\vXXX\CFX\bin\cfx5pre.exe。
4. 转换失败：查看页面日志及 local-def-service\server-error.log，并检查许可证、模型和 CFX 版本。
