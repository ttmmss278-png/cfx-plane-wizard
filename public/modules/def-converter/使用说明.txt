CFX 批量转 DEF — GitHub 前端版 V3.0
====================================

一、运行方式
1. 工具界面始终使用 GitHub Pages 最新版本。
2. 未启动本地服务时，工具箱及其他模块仍可正常使用；只有 CFX→DEF 实际转换不可用。
3. 本地 PowerShell 仅负责文件选择、目录选择、CFX-Pre 检测和转换，不再打开 localhost 旧工作台。
4. .cfx 文件和转换结果只在本机处理，不上传到 GitHub 或其他服务器。

二、首次升级
1. 关闭旧的黑色 PowerShell 服务窗口。
2. 下载并完整解压“CFX批量转DEF_GitHub前端版 V3.0”。
3. 双击“安装网页启动器.bat”，重新注册 pelton-toolbox:// 协议。
4. 返回 GitHub 工具箱的“CFX 批量转 DEF”模块。
5. 点击顶部“启动本地服务”，页面会保持在 GitHub，不再进入 127.0.0.1 旧工作台。
6. 浏览器首次访问本机服务时，若出现“允许本地网络/环回网络访问”提示，请选择允许。

三、日常操作
1. 点击“启动本地服务”。
2. 保持黑色 PowerShell 服务窗口开启。
3. 等页面显示“本地服务已连接”。
4. 选择 .cfx 文件、DEF 输出目录和 cfx5pre.exe。
5. 点击“开始批量转换”。

四、本地接口
本地服务固定监听：http://127.0.0.1:62356/
根地址会跳转到 GitHub 页面，API 只允许 GitHub Pages 和本机 localhost 来源调用。

五、关闭
优先点击页面右上角“退出工具”；也可直接关闭黑色服务窗口。正在运行的转换进程会随服务停止。

六、常见问题
1. 点击启动后仍打开旧 localhost 页面：重新运行新版“安装网页启动器.bat”。
2. 页面一直显示未连接：关闭旧服务窗口后重新启动，并确认 62356 端口未被占用。
3. 浏览器拦截本地访问：在站点权限中允许“本地网络/环回网络访问”。
4. 未找到 CFX-Pre：手动选择 ...\ANSYS Inc\vXXX\CFX\bin\cfx5pre.exe。
5. 启动失败：查看同目录 server-error.log。
