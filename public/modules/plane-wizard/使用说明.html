CFX-Post 圆截面生成器

依据圆心、半径、法向和沿程定义，生成连续 CFX-Post PLANE、CSV 与 JSON 数据。

生成前以预览中的圆心、法向和移动方向为准。若射流冲击方向与水斗运动方向不一致，应先修正坐标定义，而不是只旋转视图。

推荐流程

  1. 填写喷针域名、截面前缀、单位和小数位数。
  2. 用“三点”或“圆心 + 两点”定义基准圆。
  3. 填写沿方向的目标点或位移参数，并选择是否包含第一个圆。
  4. 先检查几何预览与法向，再生成并下载 CST/CSV。

几何校验

  • 三点不能共线；半径必须为正数。
  • 法向量不能为零，移动方向不能与预期轴线相反。
  • 单位标签只负责输出标记，不会自动换算输入数值。
  • 重名截面会覆盖 CFX-Post 中同名对象，批量生成前请检查前缀。

保存与复用

“保存”记录当前浏览器中的最近配置。修改尚未保存时，工具箱会在刷新、切换模块或打开说明前提示确认；“恢复”读取最近一次有效保存，“示例”可随时重新生成。关键工程方案建议同时下载 CSV/JSON 作为可追溯副本；浏览器清理站点数据后，本地保存可能丢失。生成结果可存入“公式与命令库”的 CST 资料页，并配套备注和提醒图片。
