偏离圆度计算

保存与恢复计算项目

  1. 完成计算后，点击页面上方“保存计算项目”，下载一个 .roundness.json 文件。轴线正在编辑时需先保存或取消；更改轴线后需重新计算，才能保存项目。
  2. 项目文件包含全部已导入的轮廓点、面积、各喷嘴已保存轴线、来源文件名、计算结果和检查提示，以及纵轴显示方式、勾选喷嘴和结果表筛选。以后恢复无需原始 CSV/TXT/Excel 文件，可换浏览器或电脑使用。
  3. 下次打开本模块，点击“打开计算项目”选择该文件，即可恢复表格和曲线，并继续编辑、计算和导出。不是在电脑上双击 JSON 文件恢复。
  4. 恢复前会检查文件格式、版本、单位，并根据文件内的原始数据复算核对。错误或损坏的项目不会覆盖当前内容；已有数据或编辑草稿时，替换前会要求确认。恢复后使用项目中的轴线，轴线自动锁定，并保存到当前浏览器。
  5. “保存计算项目”和“导出 Excel/CSV”用途不同：项目文件可以恢复完整计算，结果表只有分析数据，不能作为项目打开。项目仅在本地浏览器中处理，不上传。每个项目文件上限 256 MB，更大的数据可按喷嘴或截面分组保存。

操作步骤

页面上方的“各喷嘴中心轴线”直接显示 PZ1–PZ6 输入框，可先填写轴线，再到下方导入文件；也可先导入文件，顺序不限。导入文件不会覆盖已填坐标；同一浏览器重新打开时会恢复上次的轴线设置。文件中识别到其他喷嘴时，会自动增加其输入区。

  1. 在“各喷嘴中心轴线”中，点击相应喷嘴的“编辑”，填写实际中心轴线上的 A、B 两个三维点，再点“保存”。坐标单位 m，不能只输入平行于轴线的方向向量。坐标默认锁定；“取消”会放弃本次修改并恢复原值。
  2. 两个导入区均支持 CSV / TXT / Excel（XLSX、XLS），也支持 TSV。轮廓可使用 CFX 的 [Name]、Polyline pzN 05、[Data] 和 X/Y/Z 坐标列，或在 Excel 中保持相同数据块布局。名称中的 05 对应 0.5D，30 对应 3.0D。
  3. 轮廓也可使用逐点表格：表头为“轮廓名称、X、Y、Z”，每个点一行，重复填写所属轮廓名称（例如 Polyline pz1 05）；或使用“喷嘴、截面、X、Y、Z”，喷嘴填 PZ1 等，截面直接填 X/D（0.5、1.0 等），坐标单位 m。支持多个工作表，不允许同一截面分散在不同工作表中。
  4. 面积表首列为截面位置，例如 0.5、1.0、1.5，后续表头为 PZ1、PZ2…，面积单位 m²。文本表格支持逗号、制表符或分号分隔；简单面积 TXT 也支持空格分隔（首列表头请填“截面”）。Excel 会选择有效面积值最多的工作表。
  5. 点击“计算偏离圆度”。查看变化曲线与结果表，核对数据检查提示后按需导出 Excel、CSV 或曲线图片。

换一组数据前，可点击“导入数据”上方的“清空上次计算”：清除两个已选文件、计算结果、检查提示和曲线，保留各喷嘴已保存的轴线及正在编辑的草稿，不删除电脑上的原始文件。清空后可重新选择同一个文件。

计算方法

对每个轮廓点，计算它到所属喷嘴三维无限轴线的最短距离，取最大值 rmax 和最小值 rmin。由导入面积 S 求等面积圆半径 Req = √(S/π)。偏离圆度 = (rmax − rmin) / Req × 100%。

变化曲线

  • 横轴 X/D 为文件名称与面积表中的截面位置；纵轴默认显示偏离圆度 (%)。每个喷嘴一条折线，圆点表示成功计算的截面。
  • 纵轴可切换为“偏离圆度 C（无量纲）”，此时 C = (rmax − rmin) / Req，不乘 100%；例如 C = 0.30 对应 30%。切换仅改变曲线显示，结果表和“导出 Excel / CSV”的完整结果始终输出百分比数值。
  • 曲线区新增“导出横纵坐标”：输出一个 Excel 工作表，首列为截面 X/D（显示 0.5、1.0 等），后续列为当前勾选的 PZ1、PZ2…，按喷嘴号排序。纵坐标始终为无量纲 C，不带百分号，不受图上百分比/C 切换影响。所有坐标均为数字单元格，缺失结果留空，不补零。
  • 勾选或取消喷嘴可控制曲线显示。曲线筛选与结果表筛选独立；图片只导出当前勾选的喷嘴，数据表导出保留全部已计算结果。
  • 数据按 X/D 数值从小到大连接，不平滑、不补点。缺少面积、轴线或有其他阻断错误的截面不会进入曲线；警告点仍绘制，可在圆点悬停提示和下方结果表中核对。
  • PNG 为双倍尺寸白底图片；SVG 为可无损缩放的矢量图。图例、颜色、圆点与轴标签随图片一起导出，背景不随工具箱皮肤改变。窄屏可横向滚动查看完整曲线。

注意事项

  • 每个喷嘴独立编辑、保存或取消。保存前会检查六个坐标完整有效且两点不重合；未保存的草稿不会写入本地设置。编辑期间暂停计算和导出，已有结果仍对应上次保存的轴线；保存修改后需重新计算。
  • 同一喷嘴的所有截面共用一条中心轴线；不同喷嘴可以有不同轴线。
  • 轴线设置保存在当前浏览器本地。导入数据和结果不自动持久保存、不上传；关闭页面前请通过“保存计算项目”下载备份。
  • 文件中可以增加截面、喷嘴和轮廓点。程序按名称和表头匹配，不限制为六喷嘴或每喷嘴 12 个截面。
  • 若轮廓闭合面积与导入面积相差超过 5%，或轴线与截面法向夹角超过 2°，结果会标注检查提示，但面积仍以导入的面积文件为准。
