PELTON ENGINEERING TOOLKIT · 使用说明

CFX-Post 公式与命令库

集中管理 CEL 表达式、CCL 对象、多公式条目、层级文件夹与 CST 参考资料。

首次同步前先下载完整 JSON 备份。不要把 GitHub Token 写入条目、CST 备注、HTML 或仓库文件。

条目与多公式

  1. 选择对象类型、分类与文件夹。
  2. 多公式条目按列表顺序执行；被引用的基础公式应放在前面。
  3. 例如先定义 Temperature = 298.15 [K]，再保存引用 Temperature 的熵产表达式。
  4. 复制前检查对象名称、依赖对象和占位符。

目录与 CST

  • 先选一级分类，再选其子文件夹；文件夹可继续建立子文件夹。
  • CST 资料库属于本模块，不在主页单独占一个模块。
  • CST 与提醒图片保存在本机浏览器授权的存储中；移动或删除原文件后应检查资料状态。

GitHub 同步

工程文件不会上传。只有主动配置私有仓库后，命令库 JSON 才通过 GitHub API 同步。Token 默认只保存在当前浏览器会话；关闭浏览器后需要重新输入。同步冲突时，“使用云端版本”会采用云端内容；“合并并保留本地冲突字段”表示非冲突字段自动合并，而同一字段双方都修改时保留当前本地值。
