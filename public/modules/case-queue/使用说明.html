返回生成器

1. 打开方式

双击打开本文件夹里的 CFX连跑BAT生成器.html。网页不需要安装额外软件，也不需要启动服务器。

2. 这个工具做什么

它用于自动生成 CFX 排队运行的 .bat 文件。生成的 BAT 会按算例列表顺序运行：同一时间只启动一个算例，单个算例内部按设置的核数并行计算。

当前为双精度优化版 V2。 生成、复制和下载的 BAT 均使用 -double，与本次已验证可运行的手动双精度设置一致。已有 BAT 需要重新生成下载。

新增 CFX 自动导出模式：输入文件类型选择“CFX：自动导出 DEF 后计算”，即可把已设置完整的 .cfx 文件交给 BAT，逐例自动导出 DEF 后求解。运行只需这一个 BAT，转换脚本包含在 BAT 内，使用 Windows 自带 PowerShell。

  • 适合多个 .def 算例依次运行。
  • 支持每个算例使用同一个核数，例如 90 核。
  • 精确检测实际 CFX 求解进程，避免把仅打开的 CFX 界面误判为正在计算。
  • 自动为每个算例建立输出文件夹。
  • 支持断点续跑：自动跳过已经完成的算例，不会在重新双击 BAT 后又从第一个算例重算。
  • 自动保存 cfx_queue.log，记录每个算例的完成、跳过或失败状态。

2.1 方案、草稿与未保存提醒

顶部的方案栏可以把求解器、目录、算例队列和运行参数保存为命名方案，也可以下载或导入 JSON 方案文件。参数修改后会自动保存当前草稿，刷新页面时可继续编辑。

从工具箱切换模块、返回首页或刷新当前模块时，如果存在尚未保存到命名方案的修改，页面会先询问是否放弃。保存或重新载入命名方案后，提示会解除。重要配置建议同时下载 JSON 备份。

3. 求解器与目录

CFX 求解器路径 可以留空。留空时，生成的 BAT 会自动查找 cfx5solve.bat 或 cfx5solve.exe。

若计算机安装多套 ANSYS，建议显式填写手动成功运行所用版本的求解器路径；运行时会显示实际选择的路径。

自动查找顺序：

  • 先查 ANSYS 环境变量，例如 AWP_ROOT202。
  • 再查常见安装目录，例如 C:\Program Files\ANSYS Inc 和 D:\Program Files\ANSYS Inc。
  • 最后查系统 PATH 中是否有 cfx5solve.bat 或 cfx5solve.exe。

自动查找同时支持 cfx5solve.bat 和 cfx5solve.exe。如果自动查找失败，再手动填写完整路径，例如：

D:\ANSYS2020\ANSYS Inc\v202\CFX\bin\cfx5solve.exe

不要填写 CFD-Post\bin 目录。CFD-Post 是后处理目录，不是推荐求解器目录。

输入文件类型 默认 DEF，直接求解已有的 .def。选择 CFX 后，文件目录改为 .cfx 所在目录，BAT 在每个待算例前调用同版本 CFX-Pre 批量导出，再启动求解器。

DEF / CFX 文件目录 是所选输入文件类型所在文件夹。如果 BAT 与输入文件放在同一文件夹，保持 %~dp0 即可。

输出根目录 是计算结果输出位置。BAT 会在这里按算例名创建子文件夹，例如 PZ1、PZ2。

4. 算例队列

算例名可省略 .def 或 .cfx 后缀。例如文件是：

PZ1.def
PZ2.def
PZ3.def

网页里填写：

PZ1
PZ2
PZ3

也可以点击“导入 DEF / CFX 文件提取算例名”，选择与当前输入类型相符的文件。浏览器通常不会提供完整路径，但可以提取文件名。

4.1 直接用 CFX 文件连跑

  1. 选择“CFX：自动导出 DEF 后计算”，填写实际计算电脑上的 CFX 文件目录。
  2. 填写算例名列表，例如 4_1、4_2。单个文件支持选择，但一份 BAT 的队列使用同一种输入类型。
  3. 选择手动可打开这些 CFX 文件的 ANSYS 版本，确认网格、材料、边界、接口与求解设置已保存。此功能针对普通单配置算例；多配置或操作点的 .mdef 流程不在支持范围内。
  4. 保持严格等待模式，可提前双击 BAT，等已有计算退出后再导出和求解。
  5. 如计算电脑需要保持 CFX-Pre 打开以避免许可错误，保持“自动打开 CFX-Pre”为“是”；此时先用 -cfx 打开首个待算文件，再进行转换。

CFX-Pre 在独立批处理进程中导出，采用与工具箱“批量转 DEF”模块相同的会话命令。导出退出码、非空 DEF 和已识别致命错误共同校验；导出失败即停止，不会拿旧 DEF 继续求解。

源 CFX 不会被修改。生成的 DEF 保存到各算例输出目录下的 _cfx_generated/input.def，转换会话和日志保存在该目录的 export_... 子目录。大 CFX 会占用额外磁盘空间。

模型应包含完整网格。如果依赖外部文件（如用户 Fortran、材料数据或外部网格），这些文件仍需在计算电脑可用；复制 CFX 到导出工作目录后，原有相对路径可能需要调整。较新版本保存的 CFX 不保证能由旧版打开。

断点续跑仍按已有正常结果判断；修改源 CFX 后应换新的输出根目录，避免跳过之前的计算结果。当前本地已做模拟验证，实际 CFX 版本导出仍需用单例确认。

5. 运行参数

拓扑空间预留： 默认保持模型设置。只有运行日志明确报出 SYMASS_CS_ELIM，并要求提高 topology estimate factor 时才设置为 1.2；Ansys 文档说明这会增加内部拓扑存储估计 20%，不表示计算机总内存增加 20%。生成的 BAT 在各算例输出目录的 _cfx_queue/topology.ccl 写入专家参数，通过 -ccl 应用于本次求解；适用于 DEF 和 CFX 两种模式。写入失败会停止队列。新运行的 .out 应包含 topology estimate factor = 1.2。源文件不修改；修改此选项不会重算已完成的算例。

参考：Ansys CFX-Solver Modeling Guide，Expert Control Parameters。

计算精度： 固定使用双精度。运行开头显示 RUNNER_VERSION: 2 和 PRECISION: Double；新 .out 中应显示 Double Precision = Yes。

自动打开 CFX-Pre： 默认开启。BAT 从选定求解器的同一 CFX\bin 目录查找预处理器，DEF 模式通过 -def、CFX 模式通过 -cfx 打开首个待算文件。整个队列只启动一次保留的图形窗口；CFX 模式另外逐例运行导出批处理。若所有算例已经完成，不会启动 CFX-Pre。

CFX-Pre 启动等待秒数： 默认 60 秒，是留给程序启动和网格载入的时间，不是许可或载入成功检查。大网格或慢磁盘应适当增加。请保持自动打开的 CFX-Pre 窗口运行直到整个队列结束；BAT 不会主动关闭它。

自动打开功能用于复现本次计算电脑上已验证有效的“载入 DEF 并保持 CFX-Pre 打开”操作，不能替代修复许可证服务。如果本机直接运行求解器没有许可问题，可以将此项设为“否”。这仍会启动图形界面，不能视为完全无界面计算。

并行核数 / 分区数 对应 BAT 中的 -par-local -partition。这里应填写实际运行 BAT 的计算机可用逻辑处理器数和许可证允许的分区数；例如计算机确实有至少 90 个可用逻辑处理器时，可以填写 90。

生成的 BAT 会在实际运行时读取那台 Windows 计算机的 NUMBER_OF_PROCESSORS。如果填写值超过运行机的逻辑处理器数，会显示警告并自动降低，避免因本地 MPI 分区过多而启动失败。

检测等待秒数 是检测到已有实际 CFX 计算时等待多久再检查一次。默认 600 秒，即 10 分钟。

实际计算判定 不再使用 cfx、solver 等模糊关键词。只有以下情况才会判定为正在计算：

  • 存在精确名称为 solver-mpi.exe 的 CFX 求解进程。
  • 存在精确名称为 cfx5solve.exe，并且命令行同时包含 -batch 和 -def。

仅打开 cfx5pre.exe、cfx5post.exe、cfx5launch.exe 或 SolverManager.exe 不会被判断为正在计算。

运行模式 建议保持“严格等待已有 CFX 进程”。BAT 会在每个算例启动前精确检查是否存在实际 CFX 计算；仅打开 CFX 界面不会阻塞队列。如果发现真正的求解进程，才会按设置的秒数等待后重新检查。

6. 生成并运行 BAT

  1. 在网页里填好目录、算例名和核数。求解器路径可以先留空，让 BAT 自动查找。
  2. 点击“下载 BAT”。
  3. 把下载的 BAT 放到合适位置。推荐放在所选类型的输入文件夹。
  4. 双击 BAT 运行。
  5. 运行时会按算例列表一个接一个计算。
  6. 算例完成后，其输出子文件夹内会生成 .cfx_queue_completed 标记；以后重新运行同一 BAT 时会自动跳过该算例。
  7. 如果提示找不到求解器，再回到网页手动填写 D:\ANSYS2020\ANSYS Inc\v202\CFX\bin\cfx5solve.exe 后重新下载 BAT。

7. 常见问题

提示找不到 CFX solver launcher： 自动查找失败。请手动填写 cfx5solve.bat 或 cfx5solve.exe 的完整路径。本机可用路径是 D:\ANSYS2020\ANSYS Inc\v202\CFX\bin\cfx5solve.exe。

出现 'EnableExtensions' 或 'queue' 不是命令： 这是旧版生成 BAT 的格式问题。请刷新网页后重新下载 BAT，不要继续运行旧文件。

提示 Input file was not found： 检查输入类型、文件目录和算例名是否对应。DEF 模式找 .def，CFX 模式找 .cfx。

CFX 转换失败： 查看输出子文件夹中 _cfx_generated/export_.../attempt_... 的 stdout.log 和 stderr.log，并先确认同版本 CFX-Pre 可以手动打开源文件并导出 DEF。BAT 不会自动补齐缺失的模型设置。

如何确认检测到的是实际计算： BAT 只会显示精确匹配到的 solver-mpi.exe，或带 -batch -def 参数的 cfx5solve.exe，并列出其进程号和启动时间。

为什么重新运行时会跳过某个算例： 最新 .out 有运行结束文字、没有已识别的致命错误，且存在同名非空 .res。完成标记只作记录，旧标记或不相匹配的日志与结果不会单独导致跳过。若需要重算，请使用新的输出根目录或先移走旧结果。

如何判断成功： 求解器返回 0 后，还要通过上述日志与结果检查才能记录完成；非零返回或结果不完整会停止队列。这里的“完成”表示正常结束并生成结果，不保证已达到残差收敛目标，应另外检查求解结果。

中文目录与 BAT 格式： 下载文件采用 UTF-8 和 Windows CRLF 换行，启动时设置 UTF-8 代码页；复制后保存也应选择 UTF-8。目录含空格时不需要自行补引号。

如何查看队列运行情况： 打开输出根目录里的 cfx_queue.log，其中会记录 DONE、SKIP 或 FAILED。

CFX 或 MPI 启动失败： 新版 BAT 会先显示实际运行机的 LOGICAL_PROCESSORS，并在失败时自动输出最新 CFX .out 文件的最后 120 行。Hydra/socket 信息经常只是求解进程退出后的清理报错，真正原因通常在它之前的 .out 内容里。

核数应该填多少： 填你希望单个算例使用的并行分区数。不要超过机器可用核心和许可证允许范围。
