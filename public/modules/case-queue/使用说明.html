CFX 连跑 BAT 生成器

返回生成器

1. 打开方式

双击打开本文件夹里的 CFX连跑BAT生成器.html。网页不需要安装额外软件，也不需要启动服务器。

2. 这个工具做什么

它用于自动生成 CFX 排队运行的 .bat 文件。生成的 BAT 会按算例列表顺序运行：同一时间只启动一个算例，单个算例内部按设置的核数并行计算。

  • 适合多个 .def 算例依次运行。
  • 支持每个算例使用同一个核数，例如 90 核。
  • 精确检测实际 CFX 求解进程，避免把仅打开的 CFX 界面误判为正在计算。
  • 自动为每个算例建立输出文件夹。
  • 支持断点续跑：自动跳过已经完成的算例，不会在重新双击 BAT 后又从第一个算例重算。
  • 自动保存 cfx_queue.log，记录每个算例的完成、跳过或失败状态。

2.1 方案、草稿与未保存提醒

顶部的方案栏可以把求解器、目录、算例队列和运行参数保存为命名方案，也可以下载或导入 JSON 方案文件。参数修改后会自动保存当前草稿，刷新页面时可继续编辑。

从工具箱切换模块、返回首页或刷新当前模块时，如果存在尚未保存到命名方案的修改，页面会先询问是否放弃。保存或重新载入命名方案后，提示会解除。重要配置建议同时下载 JSON 备份。

3. 求解器与目录

CFX 求解器路径 可以留空。留空时，生成的 BAT 会自动查找 cfx5solve.bat 或 cfx5solve.exe。

当前这台电脑已经验证可用：留空时可以通过环境变量找到 D:\ANSYS2020\ANSYS Inc\v202\CFX\bin\cfx5solve.exe。因此正常情况下不需要手动填写求解器路径。

自动查找顺序：

  • 先查 ANSYS 环境变量，例如 AWP_ROOT202。
  • 再查常见安装目录，例如 C:\Program Files\ANSYS Inc 和 D:\Program Files\ANSYS Inc。
  • 最后查系统 PATH 中是否有 cfx5solve.bat 或 cfx5solve.exe。

自动查找同时支持 cfx5solve.bat 和 cfx5solve.exe。如果自动查找失败，再手动填写完整路径，例如：

D:\ANSYS2020\ANSYS Inc\v202\CFX\bin\cfx5solve.exe

不要填写 CFD-Post\bin 目录。CFD-Post 是后处理目录，不是推荐求解器目录。

DEF 文件目录 是 .def 文件所在文件夹。如果 BAT 和 .def 文件放在同一文件夹，保持 %~dp0 即可。

输出根目录 是计算结果输出位置。BAT 会在这里按算例名创建子文件夹，例如 PZ1、PZ2。

4. 算例队列

算例名不要写 .def 后缀。例如文件是：

PZ1.def
PZ2.def
PZ3.def

网页里填写：

PZ1
PZ2
PZ3

也可以点击“导入 DEF 文件提取算例名”，一次选择多个 .def 文件。浏览器通常不会提供完整路径，但可以提取文件名。

5. 运行参数

并行核数 / 分区数 对应 BAT 中的 -par-local -partition。这里应填写实际运行 BAT 的计算机可用逻辑处理器数和许可证允许的分区数；例如计算机确实有至少 90 个可用逻辑处理器时，可以填写 90。

生成的 BAT 会在实际运行时读取那台 Windows 计算机的 NUMBER_OF_PROCESSORS。如果填写值超过运行机的逻辑处理器数，会显示警告并自动降低，避免因本地 MPI 分区过多而启动失败。

检测等待秒数 是检测到已有实际 CFX 计算时等待多久再检查一次。默认 600 秒，即 10 分钟。

实际计算判定 不再使用 cfx、solver 等模糊关键词。只有以下情况才会判定为正在计算：

  • 存在精确名称为 solver-mpi.exe 的 CFX 求解进程。
  • 存在精确名称为 cfx5solve.exe，并且命令行同时包含 -batch 和 -def。

仅打开 cfx5pre.exe、cfx5post.exe、cfx5launch.exe 或 SolverManager.exe 不会被判断为正在计算。

运行模式 建议保持“严格等待已有 CFX 进程”。BAT 会在每个算例启动前精确检查是否存在实际 CFX 计算；仅打开 CFX 界面不会阻塞队列。如果发现真正的求解进程，才会按设置的秒数等待后重新检查。

6. 生成并运行 BAT

  1. 在网页里填好目录、算例名和核数。求解器路径可以先留空，让 BAT 自动查找。
  2. 点击“下载 BAT”。
  3. 把下载的 BAT 放到合适位置。推荐放在 .def 文件所在文件夹。
  4. 双击 BAT 运行。
  5. 运行时会按算例列表一个接一个计算。
  6. 算例完成后，其输出子文件夹内会生成 .cfx_queue_completed 标记；以后重新运行同一 BAT 时会自动跳过该算例。
  7. 如果提示找不到求解器，再回到网页手动填写 D:\ANSYS2020\ANSYS Inc\v202\CFX\bin\cfx5solve.exe 后重新下载 BAT。

7. 常见问题

提示找不到 CFX solver launcher： 自动查找失败。请手动填写 cfx5solve.bat 或 cfx5solve.exe 的完整路径。本机可用路径是 D:\ANSYS2020\ANSYS Inc\v202\CFX\bin\cfx5solve.exe。

出现 'EnableExtensions' 或 'queue' 不是命令： 这是旧版生成 BAT 的格式问题。请刷新网页后重新下载 BAT，不要继续运行旧文件。

提示 DEF file was not found： DEF 文件目录 或算例名写错。算例名不要带 .def 后缀。

如何确认检测到的是实际计算： BAT 只会显示精确匹配到的 solver-mpi.exe，或带 -batch -def 参数的 cfx5solve.exe，并列出其进程号和启动时间。

为什么重新运行时会跳过某个算例： 该算例输出文件夹里存在 .cfx_queue_completed，或同时存在 .res 文件和包含正常结束文字的 .out 文件。若确实需要强制重算，请先手动移走旧结果，并删除该完成标记。

如何查看队列运行情况： 打开输出根目录里的 cfx_queue.log，其中会记录 DONE、SKIP 或 FAILED。

CFX 或 MPI 启动失败： 新版 BAT 会先显示实际运行机的 LOGICAL_PROCESSORS，并在失败时自动输出最新 CFX .out 文件的最后 120 行。Hydra/socket 信息经常只是求解进程退出后的清理报错，真正原因通常在它之前的 .out 内容里。

核数应该填多少： 填你希望单个算例使用的并行分区数。不要超过机器可用核心和许可证允许范围。
