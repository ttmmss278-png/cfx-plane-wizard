ANSYS CFX Queue Runner

CFX 连跑 BAT 生成器

使用说明
生成的 BAT 会按算例列表顺序排队运行：同一时间只启动一个算例，单个算例内部按设置的核数并行；重新运行时会自动跳过已经完成的算例。支持直接使用 DEF，或在每个 CFX 算例求解前自动导出 DEF。浏览器导入文件用于提取算例名，运行时仍需填写计算电脑上的目录。
1

求解器与目录

选择输入文件类型，设置文件目录和输出根目录。求解器路径可留空，由 BAT 自动查找。

2

算例队列

填写需要排队运行的算例名，不用写 .def 或 .cfx 后缀。

3

运行参数

采用双精度计算；设置每个算例的并行核数和等待时间。

求解状态采用精确检测：只有 solver-mpi.exe，或带有 -batch 和 -def 参数的 cfx5solve.exe 才判定为正在计算。仅打开 CFX-Pre、CFD-Post、CFX Launcher 或 Solver Manager 不会被误判。
自动打开时，BAT 会用同版本 CFX-Pre 载入首个待算文件，等待后开始连跑，整批只打开一次。请保持窗口打开；若 60 秒不足以载入网格，请增加等待时间。这个选项用于已确认“保持 CFX-Pre 打开可避免许可报错”的电脑，等待时间不代表许可已验证成功。
仅当日志出现 SYMASS_CS_ELIM，并明确要求增大 topology estimate factor 时选择 1.2。BAT 会在求解前应用该参数，DEF 和 CFX 模式均支持。
4

使用提醒

运行前建议确认以下事项。

  • 求解器路径可以留空，BAT 会自动查找常见 ANSYS 安装路径；支持 CFX\bin\cfx5solve.bat 和 CFX\bin\cfx5solve.exe。
  • 不要把求解器路径指向 CFD-Post\bin，那是后处理目录。
  • 算例名必须与所选类型的 .def 或 .cfx 文件名一致，填写时可省略后缀。
  • 如果 BAT 与 DEF 文件在同一目录，DEF_DIR 和 OUT_ROOT 可以保持 %~dp0。
  • 输出目录和结果均按原始算例名命名，例如 PZ1.cfx 或 PZ1.def 的结果为 OUT_ROOT\PZ1\PZ1_001.res；运行编号由求解器分配。
  • 每个成功算例会写入 .cfx_queue_completed；重新运行 BAT 时会跳过该算例，队列状态记录在 cfx_queue.log。
  • 本地并行分区数不能超过实际运行 BAT 的计算机逻辑处理器数；BAT 会在运行时读取那台计算机的配置，并自动降低超出的数值。
  • 生成的 BAT 使用双精度；可在新运行的 .out 中核对 Double Precision = Yes。
  • CFX 模式要求文件已有完整网格和物理设置，且计算电脑上的 CFX-Pre 能打开它；缺失设置、版本不兼容或导出失败会停止队列。支持普通单配置算例，不支持多配置 .mdef 流程。
  • CFX 模式在各输出子文件夹的 _cfx_generated 内保存生成的 DEF 和转换日志，不修改源 CFX。修改 CFX 后需使用新的输出目录，避免跳过已有结果。
  • 自动打开 CFX-Pre 时只需双击 BAT；整个队列结束前保持自动打开的窗口运行。
