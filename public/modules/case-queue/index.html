ANSYS CFX Queue Runner

CFX 连跑 BAT 生成器

使用说明
生成的 BAT 会按算例列表顺序排队运行：同一时间只启动一个算例，单个算例内部按设置的核数并行；重新运行时会自动跳过已经完成的算例。浏览器通常不能读取文件完整路径，导入 DEF 文件主要用于提取算例名。
1

求解器与目录

设置 CFX 求解器路径、DEF 文件目录和输出根目录。求解器路径可留空，由 BAT 自动查找。

2

算例队列

填写需要排队运行的算例名，不用写 .def 后缀。

3

运行参数

设置每个算例的并行核数和等待时间；求解状态由 BAT 精确识别。

求解状态采用精确检测：只有 solver-mpi.exe，或带有 -batch 和 -def 参数的 cfx5solve.exe 才判定为正在计算。仅打开 CFX-Pre、CFD-Post、CFX Launcher 或 Solver Manager 不会被误判。
4

使用提醒

运行前建议确认以下事项。

  • 求解器路径可以留空，BAT 会自动查找常见 ANSYS 安装路径；支持 CFX\bin\cfx5solve.bat 和 CFX\bin\cfx5solve.exe。
  • 不要把求解器路径指向 CFD-Post\bin，那是后处理目录。
  • 算例名必须与 .def 文件名一致，但不要包含 .def。
  • 如果 BAT 与 DEF 文件在同一目录，DEF_DIR 和 OUT_ROOT 可以保持 %~dp0。
  • 输出目录会按算例名自动建子文件夹，例如 OUT_ROOT\PZ1。
  • 每个成功算例会写入 .cfx_queue_completed；重新运行 BAT 时会跳过该算例，队列状态记录在 cfx_queue.log。
  • 本地并行分区数不能超过实际运行 BAT 的计算机逻辑处理器数；BAT 会在运行时读取那台计算机的配置，并自动降低超出的数值。
